# 水縁 — SUIREN

青いベタが泳ぐ、軽量なインタラクティブ水槽です。横長の画面を中心に、ひれの揺らぎ、水草、砂利、水泡、水中に差し込む光を描きます。

HTML・CSS・JavaScriptだけで動作し、ビルドやパッケージのインストールは不要です。

## 特徴

- **ベタの遊泳**：ゆっくり泳ぐ、方向を変える、休む、水面へ上がる動きと、半透明のひれの揺らぎ。
- **水景**：揺れる水草、流木、石と砂利、上昇する水泡、水中の光。
- **餌やり**：水槽をクリックすると、その位置の水面から餌が落ち、ベタが追いかけて食べます。
- **雰囲気の切り替え**：昼・夜の照明、水の音、一時停止、全画面表示。
- **省電力モード**：フレームレートと描画解像度を抑えて動作します。
- **レスポンシブ表示**：横長の画面を主に想定し、狭い画面では操作パネルを並べ替えます。

## ローカルで起動

このリポジトリをダウンロードまたはクローンし、リポジトリのルートで次のコマンドを実行してください。Python 3を使用します。

```sh
python3 -m http.server 8080 --directory dist
```

Windowsで`python3`が見つからない場合は、次のコマンドを使用できます。

```sh
python -m http.server 8080 --directory dist
```

ブラウザで [http://localhost:8080/](http://localhost:8080/) を開きます。停止するときはターミナルで`Ctrl+C`を押してください。

JavaScriptのES Modulesを使用するため、HTMLファイルの直接起動ではなく、HTTPサーバー経由で開いてください。Python以外の静的HTTPサーバーでも`dist/`を配信できます。

## 操作

| 操作 | 動作 |
| --- | --- |
| 水槽をクリック／タップ | その位置の水面に餌を落とす |
| 「餌をあげる」ボタン／`F` | ベタの近くに餌を落とす |
| 一時停止ボタン／`Space` | 一時停止・再開 |
| 全画面ボタン／`G` | 全画面表示の切り替え |
| 昼・夜ボタン | 照明の切り替え |
| スピーカーボタン | 水の音のオン・オフ（初期状態はオフ） |
| 葉っぱのボタン | 省電力モードのオン・オフ |
| 右上の「？」 | 遊び方を表示 |

OSで「動きを減らす」が設定されている場合は、停止した状態で始まります。再生ボタンまたは餌やりで開始できます。キーボード操作時、`Space`はボタンやリンクにフォーカスがある場合、その要素の標準操作を優先します。

## 構成

| ファイル | 内容 |
| --- | --- |
| `dist/index.html` | 日本語UIと操作パネル |
| `dist/style.css` | レイアウトとレスポンシブ表示 |
| `dist/app.js` | 遊泳・餌・水泡・光のシミュレーション、操作、音声 |
| `dist/fish.js` | ベタの体、鱗、半透明のひれの描画 |
| `dist/aquascape.js` | 砂利、流木、石、水草の描画 |
| `dist/favicon.svg` | アイコン |

`dist/`内のファイルが、そのまま編集・配信できるアプリ本体です。生成用のビルド工程はありません。

## 軽量化とデータ保存

Canvas 2Dで描画し、外部ライブラリ、配信フォント、動画、画像のダウンロードは使用しません。水の音はWeb Audio APIで生成します。

標準設定では最大60fpsで動作し、描画負荷が高い場合は30fpsへ切り替えます。省電力モードでは30fps・描画解像度上限1倍、標準設定では描画解像度上限1.5倍です。背景・砂利・水草の一部・鱗をキャッシュし、タブが非表示の間は描画と音を停止します。

昼夜と省電力の設定は、ブラウザの`localStorage`に保存します。サーバー側のアプリケーションやデータベースは不要です。
